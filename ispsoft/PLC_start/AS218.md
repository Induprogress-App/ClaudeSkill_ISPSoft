# AS218 – informacje specyficzne dla modeli 

Wspólne ograniczenia serii: `AS.md`. Tutaj tylko to, co dotyczy wyłącznie AS218.
Kody CPU w pliku projektu:
- AS218RX: 3015 (`CPU=3015` w `.ini`, pole nagłówka `.isp`).
- AS218PX: 3014 (`CPU=3014` w `.ini`, pole nagłówka `.isp`).

## Bity i rejestry systemowe

- `SR169` Input value in the AD channel 2
- `SR172` Output value in the DA channel 1
- `SR173` Output value in the DA channel 2
